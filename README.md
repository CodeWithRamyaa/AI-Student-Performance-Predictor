# AI Student Performance Predictor 🎓

## About the Project

This project uses Machine Learning to predict student marks based on daily study hours and attendance percentage.

It uses Python and Linear Regression to demonstrate how student data can be used to make predictions.

## Features

* Predicts student marks.
* Takes study hours and attendance as input.
* Classifies performance into categories.
* Displays a graph of study hours versus marks.
* Validates user input.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-learn
* Linear Regression

## How It Works

1. Creates a sample student dataset.
2. Prepares study hours and attendance as input features.
3. Trains a Linear Regression model.
4. Accepts study hours and attendance from the user.
5. Predicts marks and displays a performance category.
6. Generates a graph.

## Installation

Install the required libraries:

```bash
pip install pandas matplotlib scikit-learn
```

## How to Run

Run the Python file:

```bash
python student_performance_predictor.py
```

Enter the daily study hours and attendance percentage when prompted.

## Sample Data

The project uses a small, predefined dataset for demonstration purposes.

**Note:** Predictions are educational examples, not reliable estimates of actual student performance. The model has not been validated on real-world student data.
